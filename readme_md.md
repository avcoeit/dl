# Deep Learning Lab Practicals

This repository contains practical implementations for Deep Learning lab assignments.

## 📋 Prerequisites & Installation

Before running the scripts or notebooks, make sure you have the required deep learning and data processing libraries installed:

```bash
pip install tensorflow keras matplotlib pandas scikit-learn numpy
```

## 📁 Repository Structure

Place all provided datasets and images directly in the **same directory** as the corresponding code files:

```text
├── Practical_3_Anomaly_Detection.ipynb   # (or .py)
├── credit_card_applications.csv          # Provided dataset for Practical 3
├── Practical_5_Object_Detection.ipynb    # (or .py)
├── download.jpg                          # Provided image 1 for Practical 5
├── download2.jpg                         # Provided image 2 for Practical 5
├── download3.jpg                         # Provided image 3 for Practical 5
└── README.md
```

## 🧪 Practical Details

### Practical 3: Anomaly Detection
* **Objective:** Detect anomalies and fraudulent patterns in credit card applications using Deep Learning (e.g., Autoencoders / Self-Organizing Maps).
* **Required File:** `credit_card_applications.csv` (or your provided CSV file).
* **Instructions:**
  1. Download the provided credit card application CSV dataset.
  2. Save it in the **same folder** where you have saved the Practical 3 code file.
  3. Ensure the filename in your code matches the name of your downloaded CSV file.
  4. Run the code to execute data preprocessing, model training, and anomaly detection.

---

### Practical 5: Object Detection / Image Classification
* **Objective:** Classify objects across multiple images using a pre-trained Deep Learning CNN architecture (VGG16).
* **Required Files:**
  * `download.jpg`
  * `download2.jpg`
  * `download3.jpg`
* **Instructions:**
  1. Download the 3 provided images.
  2. Save all 3 images in the **same folder** where you have saved the Practical 5 code file.
  3. Verify that the file names and extensions (e.g., `.jpg`, `.png`) match the list in your code.
  4. Run the code to view the side-by-side images and confidence score bar charts.
