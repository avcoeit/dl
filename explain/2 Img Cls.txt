
import numpy as np
import pandas as pd
import random
import tensorflow as tf
import matplotlib.pyplot as plt
from sklearn.metrics import accuracy_score

from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Flatten, Conv2D, Dense, MaxPooling2D
from tensorflow.keras.optimizers import SGD
from tensorflow.keras.utils import to_categorical
from tensorflow.keras.datasets import mnist



(X_train, y_train), (X_test, y_test) = mnist.load_data()



print(X_train.shape)


X_train[0].min(), X_train[0].max()


X_train = (X_train - 0.0) / (255.0 - 0.0)
X_test = (X_test - 0.0) / (255.0 - 0.0)
X_train[0].min(), X_train[0].max()


def plot_digit(image, digit, plt, i):
    plt.subplot(4, 5, i + 1)
    plt.imshow(image, cmap=plt.get_cmap('gray'))
    plt.title(f"Digit: {digit}")
    plt.xticks([])
    plt.yticks([])
plt.figure(figsize=(16, 10))
for i in range(20):
    plot_digit(X_train[i], y_train[i], plt, i)   
plt.show()



X_train = X_train.reshape((X_train.shape + (1,)))
X_test = X_test.reshape((X_test.shape + (1,)))


y_train[0:20]


model = Sequential([
    Conv2D(32, (3, 3), activation="relu", input_shape=(28, 28, 1)),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(100, activation="relu"),
    Dense(10, activation="softmax")
])


optimizer = SGD(learning_rate=0.01, momentum=0.9)
model.compile(
    optimizer=optimizer, 
    loss="sparse_categorical_crossentropy", 
    metrics=["accuracy"]
)
model.summary()



model.fit(X_train, y_train, epochs=10, batch_size=32)



plt.figure(figsize=(16, 10))
for i in range(20):
    image = random.choice(X_test).squeeze()
    digit = np.argmax(model.predict(image.reshape((1, 28, 28, 1)))[0], axis=-1)
    plot_digit(image, digit, plt, i)
plt.show()




predictions = np.argmax(model.predict(X_test), axis=-1)
accuracy_score(y_test, predictions)




n = random.randint(0, 9999)
plt.imshow(X_test[n])
plt.show()

predicted_value = model.predict(X_test)
print("Handwritten number in the image is= %d" % np.argmax(predicted_value[n]))





score = model.evaluate(X_test, y_test, verbose=0)
print('Test loss:', score[0]) 
print('Test accuracy:', score[1])




================================================================================
                              CODE EXPLANATION
================================================================================

1. LIBRARIES AND DATA LOADING (Cells 1 - 3)
   - TensorFlow & Keras are used to build, compile, and train the deep learning model.
   - NumPy, Matplotlib, and Scikit-learn handle numerical operations, data visualization, 
     and evaluation metrics.
   - `mnist.load_data()` fetches 70,000 grayscale images of handwritten digits (0–9), 
     partitioned into 60,000 training images (`X_train`, `y_train`) and 10,000 test images 
     (`X_test`, `y_test`). Each image has a shape of (28, 28).

2. PREPROCESSING & NORMALIZATION (Cells 4 - 8)
   - Pixel Scaling: Raw pixel intensities range from 0 to 255. Applying min-max scaling 
     via `(X - 0.0) / (255.0 - 0.0)` maps all pixel values to the range [0.0, 1.0]. This 
     prevents exploding gradients and accelerates gradient descent convergence.
   - Channel Reshape: 2D Convolutional layers in Keras expect input tensors with shape 
     `(batch_size, height, width, channels)`. The reshape appends a channel dimension of 1 
     (grayscale), changing shapes from `(60000, 28, 28)` to `(60000, 28, 28, 1)`.

3. MODEL ARCHITECTURE (Cells 9 - 10)
   - Conv2D(32, (3, 3), activation="relu"): Extracts 32 spatial feature maps using 3x3 
     kernels. Output shape becomes (26, 26, 32).
   - MaxPooling2D((2, 2)): Downsamples spatial dimensions by a factor of 2, reducing 
     dimensions to (13, 13, 32) and providing spatial translation invariance.
   - Flatten(): Converts the 3D feature representation (13, 13, 32) into a 1D vector of 
     size 5,408 (13 * 13 * 32).
   - Dense(100, activation="relu"): Fully connected hidden layer with 100 neurons learning 
     non-linear combinations of the flattened features.
   - Dense(10, activation="softmax"): Output layer with 10 units outputting a probability 
     distribution over the 10 digit classes (0 to 9).
   - Optimizer & Loss: Uses Stochastic Gradient Descent (`SGD`) with `learning_rate=0.01` 
     and `momentum=0.9`. The loss function `sparse_categorical_crossentropy` is selected 
     because the target labels (`y_train`, `y_test`) are integer class labels rather than 
     one-hot encoded vectors.

4. MODEL TRAINING (Cell 11)
   - The model is trained for 10 epochs using a mini-batch size of 32 (1875 steps per epoch).
   - Across 10 epochs, the training loss decreases from 0.2314 to 0.0055, while accuracy 
     increases from 93.05% to 99.89%.

5. INFERENCE AND EVALUATION (Cells 12 - 16)
   - Inference uses `np.argmax(..., axis=-1)` on the softmax output probabilities to extract 
     the predicted class with the highest probability.
   - The trained CNN achieves an overall test accuracy of ~98.72% and a test loss of ~0.0462, 
     demonstrating strong generalization on unseen test data.
